# 서천꽃밭

서쪽 하늘 끝 서천꽃밭에는 세상 사람마다 자기 꽃이 한 송이씩 피어 있다.
그 꽃들은 하나하나 서로 다르다.

제주 무가 「이공본풀이」의 서천꽃밭에서 착상한 웹 미디어아트입니다.

## 기능

- **끝없는 꽃밭** — 꽃밭의 칸마다 정해진 꽃이 핍니다. 가까이 가면 꽃 한 송이 한 송이가 보이고, 멀리 물러나면 수십만 송이가 은하처럼 펼쳐집니다.
- **나만의 꽃** — 이름(과 생일)을 넣으면 그 사람만의 꽃이 정해집니다. 같은 이름·생일이면 언제나 같은 꽃이 같은 자리에 핍니다.
- **꽃이 피어나는 장면** — 내 꽃 자리로 날아가면 봉오리가 열리며 꽃이 핍니다.
- **꽃 이름 짓기** — 빛깔·꽃잎 수·꽃잎 모양으로 이름이 붙습니다(예: 쪽빛 일곱잎 물결꽃).
- **이미지 저장 · 링크 보내기** — 1080×1350 카드 이미지로 저장하거나, 내 꽃으로 바로 가는 링크를 보낼 수 있습니다. 링크에는 생일이 들어가지 않습니다.
- 다른 꽃을 누르면 "이름 모를 이의 꽃"의 이름도 볼 수 있습니다.
